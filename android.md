# Прокси на Android

[На главную](README.md)

Основной вариант — [AndroidMegaProxy](https://github.com/andre487/AndroidMegaProxy), приложение MegaProxy. Оно направляет трафик через ваш сервер с помощью системного разрешения Android на VPN. Нужен Android 8 или новее и файл `MegaProxy.json` из [инструкции по серверу](server.md) либо данные своего прокси.

## 1. Установите приложение

1. На телефоне скачайте [mega-proxy-universal.apk](https://github.com/andre487/AndroidMegaProxy/releases/latest/download/mega-proxy-universal.apk). APK — установочный файл приложения.
2. Откройте скачанный файл из загрузок.
3. Если Android попросит разрешение, откройте **Настройки** в этом запросе и включите **Разрешить из этого источника** для браузера или файлового менеджера, которым открыли файл.
4. Вернитесь к установке, нажмите **Установить**, затем **Открыть**. После установки разрешение на установку из этого источника можно выключить.
5. Разрешите уведомления, если приложение попросит: в них видно состояние подключения.

Если установка не получается, откройте [подробную инструкцию на русском](https://github.com/andre487/AndroidMegaProxy/blob/main/docs/ru/installation.md). Скачивайте APK из официальных релизов проекта, а не из случайных сайтов и чатов.

## 2. Добавьте свой прокси

1. Передайте `MegaProxy.json` на телефон приватным способом, например по USB.
2. В MegaProxy откройте меню импорта, выберите этот файл и подтвердите импорт.
3. Выберите профиль HTTPS своего сервера. Пока оставьте стандартные настройки и подключение для всех приложений.

Если файла нет, создайте профиль **HTTPS** вручную: укажите домен без `https://`, порт, логин и пароль пользователя прокси. Эти данные выдаёт владелец сервера; для своего сервера они создаются мастером установки. Проверку сертификата оставьте включённой.

## 3. Подключитесь и проверьте

1. В меню главного экрана запустите проверку соединения. Она должна пройти успешно и показать внешний IP вашего сервера.
2. Нажмите **Подключить**.
3. В системном запросе Android на VPN нажмите **ОК** или **Разрешить**.
4. Откройте нужный сайт и приложение. Проверьте отдельно по Wi-Fi и через мобильный интернет.

На Android одновременно обычно работает одно VPN-подключение. Если включён другой VPN, отключите его перед подключением MegaProxy. Для выключения своего прокси нажмите **Отключить** в MegaProxy.

После успешной проверки при желании выберите, какие приложения направлять через прокси. Некоторые функции, которым нужен UDP, например отдельные звонки и игры, могут не работать через HTTPS-прокси.

## Если не работает

- **APK не устанавливается:** проверьте разрешение на установку и версию Android; воспользуйтесь подробной инструкцией выше.
- **Ошибка авторизации:** проверьте логин и пароль прокси.
- **Ошибка сертификата:** проверьте адрес и сертификат сервера, не разрешайте недоверенные сертификаты ради обхода ошибки.
- **Работает по Wi-Fi, но не по мобильной сети:** сравните результаты проверки в обеих сетях и передайте агенту текст ошибки. Это может быть блокировка со стороны оператора.
- **Соединение пропадает при выключенном экране:** проверьте ограничения работы MegaProxy в фоне и экономию батареи на телефоне.

Обновляйте приложение установкой нового официального APK поверх старого. Не удаляйте приложение перед обновлением, чтобы сохранить настройки.

## Альтернатива из Google Play: Super Proxy

Можно использовать [Super Proxy](https://play.google.com/store/apps/details?id=com.scheler.superproxy). **По опыту автора этой инструкции, в большинстве городов на мобильных сетях этот вариант заблокирован.** Поэтому основным вариантом здесь остаётся AndroidMegaProxy; доступность Super Proxy можно отдельно проверить по Wi-Fi и у своего оператора.

В Super Proxy добавьте HTTPS-прокси, укажите адрес, порт, логин и пароль, запустите подключение и разрешите VPN в запросе Android. Если соединение не работает в мобильной сети, вернитесь к основному варианту и проверьте его. Это не гарантия, что ваш сервер доступен у любого оператора.

Для помощи передайте агенту [инструкцию](agent-guide.md), модель телефона и текст ошибки без паролей.
