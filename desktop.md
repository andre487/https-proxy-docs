# Настройка прокси на десктопе

Рекомендуется использовать для проксированного трафика отдельный браузер с расширением FoxyProxy.

Лучше всего справляется Firefox, но можно использовать и браузеры на базе Chromium.

Расширение FoxyProxy:

* [Firefox](https://addons.mozilla.org/ru/firefox/addon/foxyproxy-standard/)
* [Chrome](https://chromewebstore.google.com/detail/foxyproxy/gcknhkkoolaabfmlnjonogaaifnjlfnp)
