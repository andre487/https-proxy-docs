# Прокси в браузере компьютера

[На главную](README.md)

Используем [BrowserMegaProxy](https://github.com/andre487/BrowserMegaProxy). Вам нужен файл `MegaProxy.json` из [инструкции по серверу](server.md) или данные подключения от владельца прокси.

## 1. Установите расширение

Самый простой путь — Chrome на компьютере:

1. Откройте [MegaProxy в Chrome Web Store](https://chromewebstore.google.com/detail/megaproxy/kfilelfnldddoncicbampiojjjcpbigo).
2. Нажмите **Установить** и подтвердите установку расширения.
3. Нажмите значок пазла справа от адресной строки и закрепите MegaProxy, чтобы его значок был виден.

Для других браузеров смотрите [актуальные способы установки](https://github.com/andre487/BrowserMegaProxy#build-and-install). В Firefox временное расширение исчезает после перезапуска; для постоянной установки нужен подписанный пакет. Safari не поддерживается. Обычный Chrome на Android расширения не устанавливает — для телефона используйте [приложение](android.md).

## 2. Добавьте свой прокси

1. Нажмите значок MegaProxy и откройте **Настройки**. При необходимости выберите русский язык.
2. Найдите **Импорт настроек**, выберите `MegaProxy.json`, просмотрите результат и подтвердите импорт.
3. Выберите профиль своего **HTTPS-прокси**. Импорт сам по себе не включает подключение.

Если файла нет, добавьте профиль вручную:

| Поле | Что указать |
| --- | --- |
| Название | Любое понятное имя, например «Мой прокси» |
| Тип | HTTPS |
| Сервер | Домен прокси без `https://` и без пути |
| Порт | Порт из настроек сервера, обычно `443` |
| Логин и пароль | Данные пользователя прокси, не администратора сервера |
| Knock host | Адрес, указанный при настройке маскирования на сервере; иначе оставьте пустым |

Knock host — сайт, который расширение открывает для начала авторизации. Если на сервере включено маскирование, в Chrome это поле особенно важно. При импорте готового файла оно переносится автоматически; не подставляйте случайный сайт.

Пароли по умолчанию участвуют в синхронизации браузера. Если это вам не нужно, отключите синхронизацию паролей в настройках MegaProxy.

## 3. Подключитесь и проверьте

1. Выберите профиль и включите режим **Прокси**.
2. Нажмите **Проверить подключение**. Проверка должна успешно открыть HTTPS-страницу и показать внешний IP вашего сервера.
3. Откройте нужный сайт. Если он был открыт до подключения, обновите страницу.

Для отключения нажмите **Отключить**: браузер вернётся к системным настройкам подключения. Другие приложения компьютера расширение не подключает.

## Если не работает

- **Ошибка логина или пароля:** проверьте данные пользователя прокси и Knock host, если включено маскирование.
- **Ошибка сертификата:** проверьте домен и сертификат на сервере. Не отключайте проверку сертификата.
- **Долгое ожидание:** проверьте интернет и доступность сервера; попробуйте другую сеть.
- **Расширение не управляет прокси:** отключите другие расширения для прокси и повторите подключение.

Если нужна помощь, передайте агенту [инструкцию](agent-guide.md), название браузера и текст ошибки без паролей.
