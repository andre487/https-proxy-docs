# Свой прокси: простая инструкция

Прокси — ваш сервер, через который устройство открывает сайты и подключается к интернету. Здесь настраиваем его с помощью [MegaProxyServer](https://github.com/andre487/MegaProxyServer), а подключаемся через [BrowserMegaProxy](https://github.com/andre487/BrowserMegaProxy) на компьютере и [AndroidMegaProxy](https://github.com/andre487/AndroidMegaProxy) на телефоне.

Программировать не нужно. Для своего сервера понадобятся аренда сервера, домен и компьютер. Сервер и домен обычно платные; приложения сами по себе не дают готовый прокси.

## С чего начать

1. **Нет своего сервера?** Пройдите [установку сервера](server.md). Получите файл настроек `MegaProxy.json`.
2. **Нужен прокси в браузере компьютера?** Пройдите [настройку BrowserMegaProxy](desktop.md). Расширение работает только в этом браузере.
3. **Нужен прокси для приложений Android?** Пройдите [настройку AndroidMegaProxy](android.md).

Если доверенный человек уже дал вам файл настроек или адрес, порт, логин и пароль прокси, начинайте сразу со второго или третьего пункта.

Сначала проверьте обычное подключение. Выбор отдельных сайтов и приложений можно настроить потом. Работа зависит от вашей сети: ни один вариант не гарантирует обход всех блокировок.

## Если нужна помощь агента

Откройте [инструкцию для агента](agent-guide.md), скопируйте весь текст и отправьте своему ИИ-помощнику вместе с сообщением:

> Помоги мне настроить свой прокси по этой инструкции. Я новичок. Давай по одному шагу и жди моего результата. Сначала узнай, какие у меня устройства и есть ли сервер.

Если помощник умеет читать ссылки, можно передать ссылку на этот файл в GitHub. Если не умеет — вставьте текст. Пароли, приватные ключи и файл `MegaProxy.json` в чат не отправляйте.
